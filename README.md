# 🏥 Hospital Stay Prediction

This project is a **Hospital Stay Prediction** application built with **Machine Learning** and **Flask**. It uses an **LGM (LightGBM) model** to predict the length of hospital stay based on patient data.

---

## 🌟 Project Overview
Predicting hospital stay duration helps optimize hospital resource management and patient care. This web application allows users to input patient details and receive a **prediction** of their expected hospital stay duration, aiding in efficient hospital operations.

---

## 🎯 Features
- 🤖 **Machine Learning Model**: Uses **LGM (LightGBM)** for efficient and accurate predictions.
- 🌐 **Web Interface**: User-friendly interface built with **Flask**.
- 📊 **Real-time Predictions**: Predicts hospital stay duration based on patient input.
- 🏥 **Medical Insights**: Helps hospitals manage resources and improve patient care.

---

## 🛠 Technology Stack
- **Backend**: Flask
- **Frontend**: HTML, CSS, JavaScript
- **Machine Learning**: LightGBM (LGM), scikit-learn, Pandas
- **Database**: SQLite / PostgreSQL (optional)

---

## 📂 Dataset
The model uses a dataset (`hospital_stay.csv`) for training and evaluation.

**Note**: The dataset file should be handled properly to avoid exceeding repository size limits.

## 🚀 Getting Started

### Prerequisites
Ensure you have **Python** installed on your system.

1. Clone the repository:
   ```bash
   https://github.com/Yuvapriya632/Hospital_Stay_Days
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Flask application:
   ```bash
   python app.py
   ```

---

## 🌐 Access the Application
### Open a web browser and go to: http://127.0.0.1:5000/
### Enter patient data to receive a prediction of hospital stay duration.
